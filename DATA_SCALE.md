# Local data scale (build calibration)

Founder calibration for local footprint while building — **not** an excuse to soft-claim product readiness.

## Ecosystem media / software class

- Autodesk suite install was **~100GB+**.
- Target local **FCA Ecosystem** footprint (apps + corpora + media stacks, excluding the growing construction token generator) should trend toward **~200GB** class on builder machines.
- That scale lives primarily under ecosystem CTE/Academy media, document stores, and model artifacts — not as empty repo padding.

## Construction token generator (separate)

- Currently approaching **~200B** tokens with a goal of **200T+**.
- This is **training/data generation inventory**, independent of the Auricrux App or Ecosystem runtime containers.
- Product quality bars still require promoted weights + evals; raw token count alone does not green a claims row.

## Auricrux App capability bar (this repo)

Must reach major-player parity **plus** construction specialist depth:

- Multi-model routing
- TTS + STT
- Documents / files / folders
- Image generation
- Video generation (storyboard + ffmpeg stitch when available)
- Multiple memory persistence backends (session / JSONL / SQLite)
- Optional attach to FCA Ecosystem accounts/entitlements
